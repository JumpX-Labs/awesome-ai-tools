# JumpX AI 产品与工具推荐

面向课程与日常练习整理的**好用、常用**清单，便于检索与跳转；**大模型对话与多模态生成**靠前，其余按场景分组。

## 常用大模型对话

- [ChatGPT](https://chatgpt.com/) - OpenAI，通用对话、写作与插件生态
- [Claude](https://claude.ai/) - Anthropic 网页对话，长上下文与推理
- [Claude Desktop](https://claude.ai/download) - 官方桌面客户端（Win / Mac）
- [Gemini](https://gemini.google.com/) - Google，多模态与搜索场景
- [DeepSeek](https://chat.deepseek.com/) - 国产强推理，对话与编程向
- [豆包](https://www.doubao.com/) - 字节跳动，中文日常与免费额度友好
- [通义千问](https://tongyi.aliyun.com/qianwen/) - 阿里大模型对话
- [Kimi](https://kimi.moonshot.cn/) - 月之暗面，长文与网页摘要
- [Perplexity](https://www.perplexity.ai/) - AI 搜索与引用式问答，研究与信息检索

## AI 多模态
- [ChatGPT 图像 · GPT Image 2](https://openai.com/index/new-chatgpt-images-is-here/) - ChatGPT 内置生图与编辑；API 模型与参数以 OpenAI 开发者文档「Image generation」章节为准
- [Seedance](https://seed.bytedance.com/zh/seedance) - 字节 Seed 视频生成线，含 Seedance 2.0 等；在即梦、豆包、火山方舟等落地
- [Seedream](https://seed.bytedance.com/zh/seedream4_0) - 字节 Seed 图像生成与编辑线（多参考图、高分辨率等；具体版本以官网为准）
- [即梦](https://jimeng.jianying.com/) - 字节系 AI 创作入口，集成 Seedance / Seedream 等能力（入口以官网为准）
- [可灵 AI](https://klingai.com/) - 快手系 AI 视频与图像，常与字节 Seed 线对照使用
- [HappyHourse](https://happyhourse.ai/) - 文生视频、图生视频、图像与参考素材、同步音轨等一站式（Happy Horse 1.0；官网品牌拼写为 HappyHourse）
- [Runway](https://runwayml.com/) - 文生视频、图生视频与剪辑向工作流（国际产品）
- [Replicate](https://replicate.com/) - 云端 API 运行社区多模态模型（图/视频/音频等）
